修复首页、番剧搜索和详情列表因旧 API 地址失效而空白的问题，改用官方新版客户端内置的 API 域名。

兼容当前播放线路接口将 Protobuf 字节包装为 JSON 数组的响应，修复播放页和离线缓存无法解析线路的问题。

新增离线缓存：播放页选择线路与多集下载，首页「缓存」查看队列，暂停／继续／失败重试／删除，按番剧归类，支持断网本地播放和记忆播放位置。缓存视频时会一并保存 AniCh 聚合弹幕，已缓存的视频也能在联网时单独补充弹幕；离线播放器支持弹幕、拖动／双击快进、倍速和长按 2 倍速播放。

支持 MP4 等直接视频文件、M3U8 VOD（含 AES-128 密钥、初始化片段、字节范围）；独立外置音轨、DRM 和直播列表会明确提示换线路。

独立包名 io.github.upwon.anich.offline，显示名「AniCh Pro」，可与原 AniCh／像宿同时安装。两个应用的数据分别保存，不迁移原应用数据。

使用固定 release 签名，后续同包名版本可覆盖升级。缓存时显示 Android 常驻进度通知，并以前台服务维持后台下载；系统杀进程后未完成任务变为暂停，可手动继续。网络中断时保留已下载部分并支持续传，错误提示不会显示带签名的临时视频链接。离线播放暂不带在线弹幕。

现代 Android 手机请下载 AniCh-Offline-arm64.apk；旧 32 位手机选择 armv7；模拟器选择 x86_64。
